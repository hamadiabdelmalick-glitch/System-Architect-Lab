System Architect Lab - Garage

Plateforme de gestion d'une flotte de véhicules, déployée via docker-compose dans le cadre du mini-projet Linux, Ordonnancement et Conteneurisation.

Services actifs

  • MySQL 8.0 - port 3306 (base garage)
  • Debian Lab - conteneur Bash interactif
  • Apache HTTP - port 8080 (cette page)

Commandes utiles

  • docker-compose up -d - démarrer la stack
  • docker exec -it debian_lab bash - accès au lab
  • docker exec -it garage_mysql mysql -u root -p - accès MySQL
  • docker-compose down - arrêter proprement
